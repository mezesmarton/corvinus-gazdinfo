> [!abstract] Összefoglaló
> Ez a jegyzet az IT Architektúra kurzus 6. előadását foglalja össze, amelynek fókuszában a Linux operációs rendszerek (különösen a Debian) Azure felhőkörnyezetben történő használata áll. A tananyag részletezi a Windows és a Linux rendszerek közötti alapvető architektúrális különbségeket, a fájlrendszerek és jogosultságok kezelését, a legfontosabb Bash parancsokat (navigáció, hálózat, folyamatok), valamint a shell scriptek írásának alapjait.

## 1. Operációs Rendszerek a Felhőben és a Linux Alapjai

Míg a mindennapi asztali számítógépeken (PC) a Windows dominál, a felhő alapú infrastruktúrákban (mint a Microsoft Azure) és a szerverkörnyezetekben a Linux a legelterjedtebb operációs rendszer.

> [!definition] Linux és Disztribúciók
> A **Linux** szűkebb értelemben magát az operációs rendszer magját (a nyílt forráskódú *kernelt*) jelenti.
> A **Disztribúció (Distro)** egy használható, teljes rendszer, amely tartalmazza a kernelt, a rendszereszközöket, a csomagkezelőt és a felhasználói programokat (pl. Debian, Ubuntu, RHEL). Az Azure gyakorlatokon Debian-t használunk.

### Windows vs. Linux - Alapvető Különbségek

| Feladat / Szempont | Linux (Debian) | Windows Server (PowerShell / GUI) |
| :--- | :--- | :--- |
| **Folyamatkezelés** | `ps aux`, `top`/`htop`, PID, `kill` | Task Manager, `Get-Process`, PID, `Stop-Process` |
| **Szolgáltatások (Démonok)** | `systemd` (`systemctl status ssh`) | Service Control Manager (`Get-Service`) |
| **Jogosultságkezelés** | Egyszerű `rwx` (Tulajdonos, Csoport, Mások) | Komplex NTFS (ACL - Hozzáférés-vezérlési listák) |
| **Fájlrendszer (Gyökér)** | Egyetlen közös gyökér: `/` | Meghajtóbetűjelek: `C:\`, `D:\` |
| **Felhasználókezelés** | Helyi fiókok (`/etc/passwd`), `UID` | Helyi fiókok vagy Tartományi (AD DS) felhasználók |

> [!done] 💡 Érthető magyarázat a Fájlrendszerekhez
> Windows alatt a gépedbe dugott pendrive vagy új merevlemez kap egy saját betűjelet (pl. `E:\`). Linux alatt viszont egyetlen nagy fa létezik (a `/` gyökér). Ha bedugsz egy pendrive-ot, azt nem "E meghajtóként" látod, hanem be kell csatolni (mount) a meglévő fába, például egy `/mnt/usb` nevű mappába.

## 2. Kommunikáció az Azure Linux VM-mel: Az SSH és a Bash

Az Azure felhőben futó Linux virtuális gépeket (VM) ritkán kezeljük grafikus felületen. Helyette távolról, parancssoros eléréssel csatlakozunk.

> [!definition] SSH (Secure Shell)
> Titkosított hálózati protokoll, amely biztonságos parancssori (terminál) bejelentkezést és távvezérlést tesz lehetővé egy szerveren. (Azure hálózati biztonsági csoportban - NSG - engedélyezni kell a bejövő TCP 22-es portot).
> Csatlakozás Windows-ból (PowerShell): `ssh azureuser@PUBLIC_IP`

> [!definition] Bash (Bourne Again SHell)
> A Debian (és sok más Linux) alapértelmezett parancsértelmezője (shell). Ez fogadja a terminálba beírt szöveges parancsokat, lefordítja őket az operációs rendszer számára, és visszadja az eredményt.

### A Bash Parancsok Felépítése
Egy Linux parancs általában három részből áll: `Parancsnév [-Opciók] [Argumentumok]`

> [!example] Példa a parancs felépítésére
> `ls -l /home`
> *   **`ls`**: A parancs neve (listázás).
> *   **`-l`**: Opció/Kapcsoló (hogyan csinálja? "long", azaz részletes formátumban).
> *   **`/home`**: Argumentum (mire vonatkozik a parancs? A /home mappára).

*(Fontos: A Linux szigorúan kis- és nagybetűérzékeny! Az `LS` nem egyenlő az `ls`-sel).*

## 3. A Legfontosabb Linux Fájlkezelő Parancsok

A Linux fájlrendszerben való tájékozódáshoz és fájlműveletekhez az alábbi parancsokat használjuk (zárójelben a PowerShell megfelelője):

*   **`ls`** (`Get-ChildItem`): Mappa tartalmának listázása (pl. `ls -l` a részletes lista, `ls -a` a rejtett fájlokat is mutatja).
*   **`cd`** (`Set-Location`): Belépés egy mappába. (A `cd ..` egy szinttel feljebb lép, a `cd ~` a felhasználó saját, home mappájába).
*   **`pwd`**: Kiírja a jelenlegi mappa teljes elérési útját (Print Working Directory).
*   **`mkdir`** (`New-Item`): Új mappa létrehozása (pl. `mkdir -p /tmp/proba` létrehozza a szülőkönyvtárakat is).
*   **`cp`** (`Copy-Item`): Fájl vagy mappa másolása.
*   **`mv`** (`Move-Item` / `Rename-Item`): Fájl mozgatása, vagy átnevezése.
*   **`rm`** (`Remove-Item`): Fájl törlése. Mappa (és tartalmának) törléséhez: `rm -r`. Mielőtt megkérdezi, figyelmeztetés nélkül töröl!

## 4. Jogosultságkezelés (rwx)

A Linux egy nagyon egyszerű, de hatékony háromszintű jogosultságkezelési modellt használ. Minden fájlhoz és mappához 3 jog (`r` = Read/Olvasás, `w` = Write/Írás, `x` = eXecute/Végrehajtás) állítható be 3 különböző szereplő számára:
1.  **Tulajdonos (Owner/User)**
2.  **Tulajdonos csoport (Group)**
3.  **Mindenki más (Others)**

> [!definition] chmod
> A `chmod` paranccsal változtathatjuk meg a jogosultságokat. 
> Ezt megtehetjük betűkkel (pl. `chmod go-x proba.sh` elveszi a végrehajtási jogot a csoporttól és a többiektől) vagy számokkal (oktális rendszer).
> Számoknál: r=4, w=2, x=1. Például a `chmod 744 fájl` (7=4+2+1, teljes jog a tulajdonosnak, 4=csak olvasás a csoportnak és másoknak).

## 5. Folyamatok, Szolgáltatások és Hálózat

Ezek a parancsok elengedhetetlenek a szerver üzemeltetéséhez.

| Terület | Parancs | Leírás |
| :--- | :--- | :--- |
| **Folyamatok** | `ps aux` | Kilistázza a rendszerben futó összes folyamatot (PID, process identifier is látszik). |
| **Folyamatok** | `kill -9 <PID>` | Kényszerítve ("kilövi") leállítja a megadott azonosítójú folyamatot (SIGKILL). |
| **Szolgáltatások**| `systemctl status ssh` | Ellenőrzi a háttérben futó szolgáltatás (démon), pl. az SSH szerver állapotát. |
| **Hálózat** | `ip a` | Kilistázza a hálózati interfészeket és az IP-címeket. |
| **Hálózat** | `ping -c 4 index.hu` | Ellenőrzi az IP-összeköttetést (4 csomagot küld). |

### A Csővezeték (Pipeline) és Szövegkezelés

A Linux egyik legnagyobb ereje, hogy a parancsok kimenetét át lehet irányítani egy másik parancs bemenetére a `|` (pipe) jellel.

*   **`grep`**: Szűri a szöveget. Pl. `ps aux | grep ssh` (Kilistázza az összes folyamatot, de csak azokat a sorokat írja ki, amiben szerepel az "ssh" szó).
*   **`tee`**: Egy parancs kimenetét kiírja a képernyőre, ÉS el is menti egy fájlba.
*   **`> `**: A kimenetet egy fájlba írja (felülírja). **`>>`**: Hozzáfűzi a fájl végéhez.

## 6. Shell Szkriptek Alapjai

A shell szkript nem más, mint Linux parancsok sorozata egyetlen szöveges fájlba írva, automatizálás céljából. A fájlnak végrehajtási jogot kell adni (`chmod +x script.sh`), majd a `./script.sh` paranccsal futtatható.

> [!warning] Fontos szkriptelési szabályok Bash-ben
> *   Változó értékadásánál (szemben a PowerShell-lel) **TILOS szóközt hagyni** az egyenlőségjel körül: `valtozo="ertek"`.
> *   Változó értékének kiolvasásakor dollárjelet kell elé tenni: `echo $valtozo`.
> *   A szkriptnek átadott argumentumokra pozíciós változókkal hivatkozunk: `$1`, `$2`. (A `$0` a szkript neve).

**Vezérlési szerkezetek:**

**1. Elágazás (if-then-else)**
```bash
if [ "$port" -eq 22 ]; then
   echo "Ez az SSH port"
else
   echo "Ez más port"
fi
```
*(Az `if` blokkot mindig a `fi` szóval kell lezárni, a szögletes zárójeleken belül pedig kötelező a szóköz!)*

**2. Ciklus (for)**
```bash
for port in 22 80 443; do
   echo "Port száma: $port"
done
```

## Vizsgaszerű Tesztkérdések

> [!faq]- Mi a különbség a Windows fájlrendszere (pl. C:\, D:\) és a Linux fájlrendszere között?
> A Windows fizikai/logikai meghajtókhoz (C:, D:) rendel betűjeleket és azok adják a gyökeret, míg a Linuxban egyetlen, egységes gyökérkönyvtár van (`/`), és minden partíciót, merevlemezt vagy perifériát ebbe a fa-struktúrába (pl. a `/mnt` alá) kell becsatolni (mountolni).

> [!faq]- Mire szolgál a Linux rendszerekben az SSH, és melyik alapértelmezett portot használja?
> A Secure Shell (SSH) egy titkosított hálózati protokoll, amely biztonságos parancssori bejelentkezést és távvezérlést tesz lehetővé (pl. az Azure-ban futó Debian VM kezeléséhez). Alapértelmezés szerint a TCP 22-es portot használja.

> [!faq]- Ha futtatod a `chmod 744 script.sh` parancsot, milyen jogosultságokat kap a fájl tulajdonosa, a tulajdonos csoportja, és mindenki más?
> A `7` (4+2+1) alapján a tulajdonos teljes jogot (olvasás, írás, végrehajtás) kap. Az első `4` alapján a csoport csak olvasási jogot kap, a második `4` alapján pedig mindenki más (others) szintén csak olvasási jogot kap. Végrehajtani és módosítani csak a tulajdonos fogja tudni.

> [!faq]- Mi a különbség a folyamatok és szűrések (pipeline) kezelésében a Bash és a PowerShell között?
> Bár a csővezeték (`|`) karakter mindkét rendszerben megvan, a Bash alapvetően **szövegfolyamokat** (stringeket) ad át egyik parancsból a másikba (pl. `ps | grep ssh`), míg a PowerShell **objektumokat** és azok tulajdonságait (pl. `Get-Process | Where-Object`).

> [!faq]- Melyik parancsot használod Linux alatt a háttérben futó szolgáltatások (démonok) állapotának ellenőrzésére (pl. fut-e az ssh szerver)?
> Erre a `systemctl status ssh` (vagy sshd) parancsot használjuk, ami a systemd (a Linux szolgáltatáskezelője) segítségével kérdezi le az állapotot.
